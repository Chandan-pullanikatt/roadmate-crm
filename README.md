# RoadMate CRM

A production-quality MERN stack CRM with role-based dashboards.

## Structure
- `server/`: Node.js + Express + MongoDB + Socket.io
- `client/`: React + Vite + TailwindCSS + Zustand + React Query

## Roles
- Founder
- State Manager
- Industry Manager
- District Executive

## Setup
### Server
1. `cd server`
2. `npm install`
3. Create `.env` from `.env.example`
4. `npm run dev`

### Client
1. `cd client`
2. `npm install`
3. `npm run dev`
